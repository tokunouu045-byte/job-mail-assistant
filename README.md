# 求职邮件助手

一个 Microsoft Edge 浏览器扩展：读取招聘信息、识别招聘图片、整理求职邮件，再将审核后的内容填入 QQ 邮箱。**最终发送由你手动完成。**

开源版不内置任何人的简历或个人资料。无需 API 也可使用：把资料复制到 ChatGPT，生成后一次粘贴完整回复，自动拆分主题和正文。

## 功能

- 点击扩展读取当前招聘帖文字，也可直接粘贴 JD。
- 拖入 PNG/JPG/WEBP 图片，本地中文/英文 OCR；长图放大、分段处理。一次最多 6 张，每张不超过 15MB。
- ChatGPT 手动复制流程、基础模板草稿，以及可选的 OpenAI / DeepSeek API。
- 自动拆分完整邮件；收件人从招聘原文提取，多邮箱时手动选择，不使用署名中的个人邮箱。
- QQ 邮箱草稿填写、PDF 附件选择、网址超链接、默认签名保留。
- 可点选收件人输入框并记住定位信息；页面结构变化后需重新点选。

## 安装（Edge）

1. 从 [Releases](https://github.com/tokunouu045-byte/job-mail-assistant/releases/latest) 下载 `job-mail-assistant-edge-v2.0.0.zip` 并解压。也可以使用 GitHub 的 **Code → Download ZIP** 下载源码。
2. 在 Edge 地址栏输入 `edge://extensions/`。
3. 开启「开发人员模式」，点击「加载解压缩的扩展」。
4. 选择解压后的 **extension** 文件夹，其中应直接包含 `manifest.json`。
5. 将「求职邮件助手 · 开源版」固定到工具栏。

无需构建即可安装，OCR 运行库和语言模型已随包提供，因此安装包较大。保留解压目录，移动或删除目录会影响扩展运行。本项目没有上架浏览器扩展商店。

## 使用教程：无需 API

### 1. 填写资料与简历

打开扩展侧栏，展开「个人资料与 AI 设置」，填写姓名、学校、到岗安排、联系方式、作品集链接和真实经历，点击「保存个人资料」。不适用的可选信息可留空。

在「交给 QQ 邮箱」区域点击「更换」，选择自己的 PDF 简历（最大 5MB）。不要把真实简历提交到这个 GitHub 仓库。

### 2. 读取招聘

在已经登录的小红书网页中打开具体招聘帖，点击工具栏扩展图标或「重新读取当前页」。也可以在招聘原文框中直接粘贴信息。

如果 JD 是图片，把清晰原图从电脑拖入虚线框，或点击框选择图片。「识别当前屏幕」仅覆盖可见区域，整张长图请使用原图。网页图片拖动可能只有链接，请先保存原图再拖入。

默认「本地增强识别」无需联网调用 AI。识别完成后，务必核对邮箱、日期和数字。

### 3. 用 ChatGPT 起草

点击「复制资料与要求到 ChatGPT」，打开 [ChatGPT](https://chatgpt.com/) 粘贴。必要时附上招聘原图，让它结合个人资料生成邮件。

这一步使用你自行登录的 ChatGPT；扩展不读取你的 ChatGPT 对话、不获取聊天账号权限，也不会自动发送提示词。

### 4. 一次粘贴，自动拆分

把 ChatGPT 的整段回复粘贴到「粘贴 ChatGPT 完整回复」，点击「自动拆分并填入邮件」。支持以下格式和常见 Markdown 标题：

```text
邮件主题：应聘产品运营实习生-示例姓名

尊敬的招聘负责人：

您好！
这里是你的求职邮件正文。
```

主题前必须有「邮件主题：」「主题：」「标题：」或 `Subject:` 标签。原文无邮箱时自行核对补充；多个邮箱时选择正确对象。已有草稿被替换前会提示确认。

### 5. 填入 QQ 邮箱

1. 核对收件人、主题、正文、到岗信息和 PDF，补全 `【待补充】` 等占位内容。
2. 勾选「我已核对」，点击「打开 QQ 邮箱并填入草稿」。
3. 在同一 Edge 浏览器登录 QQ 邮箱，进入空白写信页。若已有写信页，可切换到该标签页，在侧栏点击「填入当前 QQ 写信页」。
4. 如果提示未识别收件人，在邮箱右下角点「点选收件人输入框」，再点击实际输入邮箱的位置；成功后会记住定位信息。
5. 若正文只有默认签名但被判定已有内容，勾选「保留现有签名」，再点填入。不会直接覆盖已有主题或收件人。
6. **检查收件地址是否已被 QQ 确认、附件是否上传成功，预览正文和链接，最后亲自点击发送。**

扩展没有自动发送功能。QQ 页面版本可能不同，自动填写属于网页适配，不是 QQ 官方接口；失败时可以使用复制和下载按钮手动填写。

## 可选：API 写信和 AI 识图

在设置中选择 OpenAI 或 DeepSeek，输入对应服务的 API 密钥和可用模型名称，点击「启用 AI」并允许相应网站权限。切换服务会清除旧密钥。然后点击「AI 定制邮件」。

- OpenAI 使用 Responses API；默认模型为 `gpt-4.1-mini`。可改为账户支持 Responses API 和 JSON 输出的模型。
- OpenAI AI 识图还要求模型支持图片输入。选择这一方式后，会在发送图片前要求确认。
- DeepSeek 使用 Chat Completions API；模型名称可编辑，以账户实际可用模型为准。
- ChatGPT 网页会员不能替代本扩展的 API 密钥或 API 额度。API 费用由服务商单独收取。
- 密钥仅保存在扩展会话存储中；重载、关闭浏览器后可能需重新配置。不要将密钥放入源码、截图或 Issue。

此方式用于个人本机安装。多人部署服务时，应采用服务端保管密钥的架构，不要向用户分发包含密钥的扩展包。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 无权读取页面 | 在扩展详情允许访问小红书，刷新招聘帖。浏览器设置页和其他扩展页面不能读取。 |
| 点生成没结果 | 看生成按钮下方的进度和错误。重新加载后需要重新启用 API。 |
| 接口返回 400 | 查看「接口原因」「参数」「模型」，不要直接归因为余额不足。 |
| 点邮箱按钮不跳转 | 看按钮下方提示，检查收件邮箱、待补充项、审核勾选和简历附件。 |
| 邮箱没有助手框 | 允许 `mail.qq.com` 及子域名的网站权限，刷新邮箱，在侧栏点「填入当前 QQ 写信页」。 |
| 收件人未识别 | 使用邮箱助手的「点选收件人输入框」。页面改版或输入框变动后可能需要重新点选。 |
| 附件没有上传 | 插件选择文件不等于 QQ 服务器上传成功，请以邮箱页面状态为准；必要时手动添加。 |
| 链接不能点 | 富文本正文会生成超链接；可在 QQ 的预览中检查，纯文本编辑器仅能保留网址文字。 |
| OCR 错字多 | 使用清晰原图；本地 OCR 无法恢复已模糊文字，可手动修正或选择 AI 识图。 |

更新扩展时保留原目录，用新文件替换后在 `edge://extensions/` 点击重新加载，再刷新 QQ 邮箱页面。开源版不会在升级时清空自定义资料或简历。

## 隐私与权限

见 [PRIVACY.md](PRIVACY.md)。没有统计脚本、运营服务器或遥测。个人资料与 PDF 存在扩展本地；草稿在会话存储中。仅在你选择 AI 功能时把相关文字或图片发给选定服务。PDF 不发送给模型。

| 权限 | 用途 |
| --- | --- |
| `activeTab`, `scripting` | 点击后读取页面、截图、填入邮箱草稿 |
| `storage` | 保存个人设置、PDF、草稿与会话密钥 |
| `sidePanel` | Edge 侧栏界面 |
| `downloads` | 下载自己选择的 PDF |
| 小红书及短链接域名 | 读取用户打开的招聘帖 |
| QQ 邮箱及子域名 | 在写信页填入草稿 |
| 可选 OpenAI / DeepSeek / 小红书图片 CDN | 启用对应功能时请求 |

## 开发与测试

需要 Node.js 20+，单元测试无需安装依赖：

```bash
npm test
```

浏览器测试使用 Playwright 和合成数据，不访问真实邮箱：

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

发布包使用 Python 3 标准库生成：

```bash
python scripts/package.py
```

结构：`extension/` 是可加载扩展；`tests/` 是合成数据测试；`scripts/` 是打包与隐私检查工具。个人简历、浏览器配置、会话和密钥不得进入仓库。

测试覆盖文本提取、收件人保护、邮件拆分、API 返回处理、模拟 QQ 页面及拖图识别。**模拟测试不能证明每个真实 QQ 版本都能填写成功；没有代表所有账户完成真实 API、登录或邮件投递测试。**

欢迎提交 Issue 或 PR。反馈时附扩展版本、浏览器版本、操作步骤和错误文字；截图请遮住收件人、联系人、个人资料与 URL 中的登录参数。
